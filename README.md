# Does Batch Size Matter? Investigating the Impact of Batch Prompting on LTL-to-NL Translation Using Open-Source LLMs

This repository contains the appendix and experimental codes for our study on batch prompting for Linear Temporal Logic-to-Natural Language (LTL-to-NL) translation using open-source Large Language Models (LLMs).

The study investigates how processing multiple LTL formulas within a single inference request affects translation quality and inference efficiency. In particular, we examine the impact of different batch sizes across multiple open-source models and prompting techniques.

Our objective is to understand whether batch prompting can reduce inference overhead and token consumption while maintaining the translation quality and semantic correctness of generated natural language descriptions.

The repository is anonymized for double-blind review.
